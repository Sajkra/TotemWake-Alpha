# TotemWake — Alpha builds

**TotemWake** is a fantasy survivor game: weapons fire automatically, you move, dodge, collect XP, capture totems,
loot chests and survive until 20:00 — then the portal opens and you face the boss, Bone Crown.

This repository only hosts **playable test builds** (no source code). Website: <https://totemwake.com>

## Download and play (Windows)
1. Open **[Releases](../../releases/latest)** and download `TotemWake_Alpha_<version>_Windows.zip`.
2. Unzip it anywhere (e.g. Desktop) — do not run it from inside the ZIP.
3. Run `TotemWake/TotemWake.exe`.
   Windows may show *"Windows protected your PC"* (the game is not signed yet) → **More info → Run anyway**.

Requirements: Windows 10/11 64-bit, a DirectX 11/12 graphics card. Keyboard + mouse or an Xbox-style gamepad.

## Controls
| Action | Keyboard / mouse | Gamepad |
|---|---|---|
| Move / camera | WASD / mouse | Left stick / right stick |
| Jump | Space | A |
| Open chest / interact | F | X |
| Drink potion | Q | Y |
| Pause, How to Play | Esc | Menu |

Attacks are automatic. Hold **Z** to enlarge the minimap.

## Feedback
Every opinion helps — what was fun, what was boring, too hard / too easy, bugs, performance.
- Open an **[Issue](../../issues/new)** (a GitHub account is needed) — screenshots are welcome.
- Or get in touch via **Join the Alpha** on <https://totemwake.com>.

When reporting a bug, please add the build number (bottom-right corner of the main menu, e.g. `build 46`) and, if the game
crashed, the log file `%USERPROFILE%\AppData\LocalLow\DanAIDev\TotemWake\Player.log`.
